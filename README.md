# qingchuan-x.github.io

个人博客，GitHub Pages + Jekyll（minima 主题）。

- 在线地址：<https://qingchuan-x.github.io>

## 写新文章

1. 在 `_posts/` 新建文件：`YYYY-MM-DD-标题.md`
2. 文件头加：

```yaml
---
title: "文章标题"
date: 2026-09-07
categories: [分类]   # 必填，如：随笔 / 技术 / 学习笔记
tags: [标签1, 标签2]  # 可选
---
```

阅读时长按正文约 400 字/分钟自动估算，无需手填。

3. Markdown 正文，git push 后约 1-2 分钟自动上线。
